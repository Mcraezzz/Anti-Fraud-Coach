# 技术路线

## MVP 架构

```text
微信小程序
  ↓
FastAPI 后端
  ↓
规则引擎 + 风险特征抽取
  ↓
知识库检索问答 + 情景训练评分
  ↓
本地模型增强：MacBERT / BGE-M3 / Qwen
```

## 模块说明

- 风险识别：`backend/app/services/risk_rules.py`
- 反诈知识问答：`backend/app/services/rag_service.py`
- 情景训练评分：`backend/app/services/training_service.py`
- 模型资源检查：`backend/app/services/model_service.py`
- 小程序识别页：`miniprogram/pages/index`
- 小程序训练页：`miniprogram/pages/train`
- 小程序报告页：`miniprogram/pages/report`

## 后续增强

1. 使用 `hfl/chinese-macbert-base` 微调诈骗类型分类器。
2. 使用 `BAAI/bge-m3` 或 `Qwen3-Embedding-0.6B` 替换当前词面检索。
3. 使用 `BAAI/bge-reranker-v2-m3` 对知识库召回结果进行重排。
4. 使用 `Qwen3-4B-Instruct-2507` 或远程大模型 API 生成更自然的解释与训练反馈。
5. 接入 `PaddleOCR`，支持聊天截图识别。
