# 项目一：Anti-Fraud Coach 微信小程序

[返回仓库总览](../README.md)

## 项目定位

面向大学生的反诈教练小程序界面与交互原型，侧重展示“风险识别 → 解释与建议 → 问答 → 情景训练 → 能力报告”的产品流程，并提供管理端展示页面。

## 技术与目录

采用 JavaScript、WXML、WXSS、微信小程序 Skyline 渲染器和 glass-easel 组件框架。

- `app.js`、`app.json`、`app.wxss`：应用入口、页面注册与全局样式。
- `pages/`：首页、识别、结果、问答、训练、报告、个人中心与管理页面。
- `components/`：品牌组件。
- `assets/`、`styles/`：图标、插图与视觉样式。
- `utils/`：路由与标签导航辅助代码。
- `project.config.json`：微信开发者工具配置。

## 已有行为与实现边界

页面包含文本、截图 OCR、链接、短信等识别入口及风险信号、处置建议、训练场景等内容。但当前这些属于界面演示：识别按钮通过定时跳转进入结果页，结果页风险标签与建议为预置内容；问答页和训练页尚未实现在线模型问答或完整的训练评估服务。

当前 `pages/` 未接入 `wx.request` 或云函数调用，因此不能将界面中的 OCR、RAG 问答或报告视为已连接真实算法。用户、能力统计和管理展示也不能视为已实现后台数据系统。

## 如何预览

1. 在微信开发者工具中导入**仓库根目录**，由 `project.config.json` 识别小程序项目。
2. 配置当前使用的 AppID。仓库默认值为 `touristappid`，并非已发布应用的 AppID。
3. 使用支持 Skyline 的开发者工具环境编译，查看页面与导航效果。

预览现有界面不需要启动 Python 项目，也不需要 Qwen 密钥。实际发布与后端接入尚需另行实现。

## 与 RAG 项目的关系

两者共享校园反诈主题与“识别—解释—训练”的设计思路，但当前没有共享运行时、请求接口或用户数据。RAG 引擎可以作为未来服务化接入的基础；这是一种后续集成方向，并非现有能力。
