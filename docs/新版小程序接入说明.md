## 接入与数据

| 功能 | 实现 |
| --- | --- |
| 文本、链接、短信 | 复用 `risk_rules.analyze_text` 和原有模型服务；链接仅分析特征，不主动浏览 |
| 截图 | 复用 `ocr_service.process_chat_screenshot`；无法识别、模型不可用、图片超限均明确报错 |
| 问答 | 复用 `rag_service.answer_question`，展示知识库参考；每次问题独立检索，不声称具备多轮记忆 |
| 六类训练 | 参考项目的情景转换为服务端题库，列表不下发分数或正确答案；服务端计算得分并返回解析 |
| 报告 | 根据当前设备实际活动计算，未练习的维度为“未评估”；六维分数按对应情景的历次得分平均，不作为心理测评或安全保证 |
| 历史与偏好 | SQLite 持久化，支持清除本人检测记录、昵称与脱敏偏好；`DELETE /api/coach/training` 仅重置本人训练记录与报告 |
| 校园看板 | 使用原有 `/api/auth/login` 登录管理员，再校验管理员身份；展示新接口产生的活动统计 |

新数据默认保存到 `backend/app/data/coach.sqlite3`，可用 `ANTI_FRAUD_COACH_DB` 修改位置。原来的 `accounts.json`、旧训练记录、已有模型与知识库未迁移或删除。看板“设备会话数”不等同于去重学生数。

设备会话令牌仅保存在当前小程序本地，服务端存储其哈希。清除小程序存储后无法找回原设备会话；这是本地 MVP 的设备模式，尚未实现微信身份登录和跨设备同步。管理员账号沿用原项目配置，不在代码中新增默认管理员。

开启脱敏后，检测结果中的手机号、身份证号、紧跟标签的验证码或密码会遮蔽；截图先由原有 OCR 逻辑脱敏。问答也对问题文本执行脱敏。该规则不能覆盖所有个人信息形式，提交前仍应检查内容。

## 稳定性与性能改进（2026-11-22）

本轮仅修改桌面项目：

- 每次请求固定目标服务地址，同一地址的并行请求共用一次会话创建；切换地址不会把旧服务令牌保存或发送到新服务。重置会话会使尚未返回的旧会话创建结果失效，管理员登录和统计请求也固定到同一服务。
- 问答只提交本次问题，历史对话继续显示在本地。后端原本不使用聊天上下文，这样可减少重复上传，也避免较长的历史回答触发请求长度校验失败。
- 历史记录在数据库层按时间取最近 50 条，同一毫秒的记录按写入次序排序；报告直接统计全部检测记录，不再读取、解析所有检测正文。新增按设备、事件类型、时间的索引，已有数据无需迁移。
- 偏好更新在写事务中重新读取最新值，避免两个同时发起的设置更新互相覆盖，也不会覆盖并发更新后的昵称。
- 六类训练推荐优先使用规则引擎的稳定类型编号，避免游戏交易等显示名称不同造成错误匹配。
- `ANTI_FRAUD_SEMANTIC_RAG=0` 同时关闭 embedding 和 reranker 模型加载，保留词法知识检索。默认启用语义检索时仍保留原有模型路径和加载方式。
