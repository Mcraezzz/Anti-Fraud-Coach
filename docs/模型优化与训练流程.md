# 模型优化与训练流程

## 1. MacBERT 反诈文本分类微调

数据抽取：

```powershell
python tools\prepare_macbert_fraud_dataset.py --max-per-source-label 2000
```

轻量微调：

```powershell
python tools\finetune_macbert_fraud.py --epochs 1 --batch-size 8 --max-train-samples 800 --max-dev-samples 200 --freeze-encoder
```

输出目录：

```text
D:\CARIC模型&数据集\models\hfl_chinese-macbert-fraud-finetuned-v2
```

后端主流程会优先检测 `hfl_chinese-macbert-fraud-finetuned-v2` 是否存在，不存在时回退到 `hfl_chinese-macbert-fraud-finetuned`。存在时，低/中风险文本会先经过微调分类器补充判断；规则或 URL 信号已足够时，仍以可解释规则链路为主。

## 2. URL 分类模型重训与兼容导出

当前本地 `khagu_malicious-url-detection-models` 只有旧版 pkl，没有原始训练 CSV。重训脚本默认使用 Hugging Face 的 `bgspaditya/malicious-600k` 四分类 URL 数据集，标签为 `benign`、`defacement`、`malware`、`phishing`。

```powershell
python tools\retrain_url_classifier.py --max-train-rows 120000 --max-test-rows 30000
```

输出文件：

```text
D:\CARIC模型&数据集\models\khagu_malicious-url-detection-models\decision_tree_current.pkl
D:\CARIC模型&数据集\models\khagu_malicious-url-detection-models\scaler_current.pkl
D:\CARIC模型&数据集\models\khagu_malicious-url-detection-models\label_encoder_current.pkl
D:\CARIC模型&数据集\models\khagu_malicious-url-detection-models\url_classifier_current_manifest.json
```

后端默认优先加载 `*_current.pkl`。如果文件不存在，会自动回退到旧版 `decision_tree.pkl`、`scaler.pkl` 和 `label_encoder.pkl`。

## 3. Qwen 预热与离线反馈

Qwen 默认关闭：

```text
ANTI_FRAUD_QWEN_ENABLED=0
```

答辩演示前可以单独预热：

```powershell
python tools\prewarm_qwen.py
```

离线生成训练题反馈：

```powershell
python tools\generate_offline_qwen_feedback.py --limit 10
```

这样可以避免每次 API 请求都加载 4B 生成模型，同时保留“本地大模型增强反馈”的展示能力。
